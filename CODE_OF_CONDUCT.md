# Code of Conduct

## Our standards

We want participation in this project to be respectful, constructive, and welcoming. Examples of positive behavior include:

- giving actionable technical feedback;
- respecting differing experience levels and viewpoints;
- focusing criticism on code and behavior, not people;
- acknowledging mistakes and helping resolve them.

Unacceptable behavior includes harassment, discriminatory language, personal attacks, publishing private information, or deliberately disrupting project work.

## Enforcement

Report conduct concerns privately to the repository owner through their GitHub profile. Reports will be reviewed fairly and kept confidential to the extent possible. Maintainers may edit or remove comments, reject contributions, or restrict participation when necessary to protect the project community.

This policy applies to repository discussions, issues, pull requests, reviews, and other project spaces.
